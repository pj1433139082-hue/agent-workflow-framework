# 框架维护标签

| 规范角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 尚待评估 |
| needs-info | needs-info | 等待缺失信息 |
| ready-for-agent | ready-for-agent | 规格完整，可按任务依赖实施 |
| ready-for-human | ready-for-human | 需要人员处理的事项 |
| wontfix | wontfix | 明确不实施 |

标签描述维护任务流转，不是业务权限或永久操作许可。ready-for-agent 不表示前置依赖已经完成；开始前仍核对 Blocked by。

只在实际需要时检查或创建对应标签，不为使用公开 CLI 强制初始化全部标签。
