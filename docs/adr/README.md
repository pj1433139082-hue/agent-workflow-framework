# 架构决策记录 (ADR)

本目录记录通用智能体协作框架系统级技术架构决策。决策遵循 ADR 格式规范，只记录难以逆转、缺少背景会令人意外且确有取舍的关键系统设计。

## 决策记录索引

- **[ADR 0001: 通用底座与业务包分离](0001-通用底座与业务包分离.md)**：通用任务定位与可替换业务包解耦，首版带两个虚构流程。
- **[ADR 0002: 任务事实与生成状态分离](0002-任务事实与生成状态分离.md)**：任务事实与派生索引单向流动，`context --write` 幂等重建索引，杜绝双事实源。
- **[ADR 0003: 项目启动按原交办范围衔接](0003-项目启动按原交办范围衔接.md)**：启动完成与业务实现解耦，按用户原请求交办范围与档位无缝衔接。
- **[ADR 0004: 任务写入共锁与恢复回执分离](0004-任务写入共锁与恢复回执分离.md)**：任务事实原子写入、索引与共锁分离，写失败出具结构化恢复回执，严禁盲目重放。
- **[ADR 0005: 业务环境独立与免安装运行时](0005-业务环境独立与免安装运行时.md)**：框架 CLI 工具环境与业务项目独立，纯文档项目不强装运行时，环境按需记录。
- **[ADR 0006: 交互档位作为执行节奏约定](0006-交互档位作为执行节奏约定.md)**：`full-auto`、`assisted`、`manual-review` 为协作停点偏好而非操作系统权限沙箱。
- **[ADR 0007: 基于配套技能的项目启动与无缝交接](0007-基于配套技能的项目启动与无缝交接.md)**：配套使用 `project-start` 技能，通过定位脚本安全调用公开 start，实现框架外工作区隔离。
- **[ADR 0008: 历史项目非破坏性纳管](0008-历史项目非破坏性纳管.md)**：原生提供 `adopt` 指令，非破坏性保留源码、Git 历史与已有配置，安全补建协作规范并自适应嗅探环境。
- **[ADR 0009: 智能体提问纪律与批处理问答](0009-智能体提问纪律与批处理问答.md)**：固化可算不问、批量集中、一键确认、可见保底、问过即锁、只读零打扰六大原则与 SHA256 证据锁。
- **[ADR 0010: 上下文Hook的零配置就地探测](0010-上下文Hook的零配置就地探测.md)**：支持自当前工作目录向上递归探测 `.agent-workflow.local.json`，消除对手工环境变量的强依赖。
- **[ADR 0011: 旧阶段决定在证据变化后可重答](0011-旧阶段决定在证据变化后可重答.md)**：已记录过答案的旧阶段决定可按当前证据重答并重绑摘要，未记录过的仍不可补答。
- **[ADR 0012: 纳管保留项目身份与本机导航标记](0012-纳管保留项目身份与本机导航标记.md)**：`adopt` 拒绝项目身份冲突，保留既有 `.agent-workflow.local.json`，回执列出任务记录与导航标记。
